# PHPCPD Report Schema
This document describes the official XML schema used by `phpcpd` to generate structured code duplication reports. This schema ensures that the exported XML is strictly typed and can be reliably parsed by external reporting tools, CI/CD pipelines, or XSLT processors (such as Xalan) to generate HTML representations.

## Version 1.0.0 Specifications
* **Namespace:** `https://systemsdk.github.io/phpcpd/report`
* **Schema Location:** [`phpcpd-report-v1_0_0.xsd`](https://systemsdk.github.io/phpcpd/report/phpcpd-report-v1_0_0.xsd)
* **Introduced In:** `phpcpd` version 8.2.0
* **Last Updated:** 2026-08-31
